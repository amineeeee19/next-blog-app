# Next Blog App

A full-stack blog application built with Next.js, React and MongoDB.

## Features

- Blog pages
- Admin dashboard
- Admin authentication
- Create and manage blog posts
- MongoDB database
- Responsive web interface

## Technologies

- Next.js
- React
- MongoDB
- Mongoose
- NextAuth
- JavaScript
